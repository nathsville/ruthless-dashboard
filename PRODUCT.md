# RUTHLESS dashboard

## Platform
web

## Stack
User selected editable React source, rather than the original minified frontend. React + TypeScript + Vite; Recharts, Lucide and local Lottie assets. This choice of React tooling keeps the project independently buildable.

## Product Purpose
Recreate the public dashboard reference at https://demos.shadcndashboard.dev/?mode=dark, preserving its layout and motion while replacing its product branding with RUTHLESS dashboard.

## Brand Commitments
RUTHLESS dashboard. The reference's dark Vega visual identity and interactions are pinned; this is not a redesign.

## Capabilities and Constraints
Editable implementation of surveyed dashboard and application routes. Local demo persistence, no claims of production payment, email delivery, authentication security, live hospital/POS integrations or AI generation. No private backend/source was supplied. Original reference bugs are documented in ANALYSIS.md; any behavior implemented differently must be disclosed.

## Evidence on Hand
ANALYSIS.md, ROUTES.md, .playwright-mcp/settled-*.png, measured tokens and motion, public resource URLs and REA evidence. Source asset licensing for public redistribution remains the user's responsibility.
